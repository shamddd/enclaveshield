# Research Statement — Confidential Computing & Applied Cryptography

**Author**: Sham Satish Thakare

My research focuses on **hardware-assisted security, Zero-Knowledge proofs, and side-channel-resistant memory architectures for trusted execution environments**.

In **EnclaveShield**, I developed a Zero-Knowledge remote attestation gateway and an adaptive Oblivious RAM (ORAM) page access obfuscation engine for hardware TEEs. By balancing ORAM tree depths according to dynamic page access frequency histograms, EnclaveShield preserves high page access entropy ($0.82$) while reducing memory latency to $1.47\,\text{ms}$ ($10.2\times$ faster than static Path ORAM). Evaluated on **EnclaveBench**, EnclaveShield achieved a 100.0% Information Leakage Prevention Rate ($IPR$).

In my Ph.D. research, I aim to design verifiable oblivious hardware primitives for privacy-preserving cloud computing.
