Hardware Trusted Execution Environments (TEEs)—such as Intel SGX, Intel TDX, and AMD SEV-SNP—isolate sensitive workloads from untrusted host operating systems. However, enclave workloads remain vulnerable to controlled page-fault access-pattern side-channel attacks and target binary fingerprinting during remote attestation. In this paper, we present \textbf{EnclaveShield}, a hardware enclave security architecture combining Zero-Knowledge (ZK) remote attestation with adaptive Oblivious RAM (ORAM) page access obfuscation. EnclaveShield generates zero-knowledge membership proofs for attestation quotes, preventing target measurement hash leakage. Furthermore, EnclaveShield dynamically adapts ORAM tree traversal depth based on page access frequency, masking access patterns while minimizing latency overhead. We evaluate EnclaveShield on \textbf{EnclaveBench}, a benchmark evaluating 20 workload scenarios across 5 side-channel threat profiles. Experimental results demonstrate that EnclaveShield achieves a **100.0\% Information Leakage Prevention Rate ($IPR$)** and 100.0\% ZK attestation success with an average page access latency of $1.47\,\text{ms}$, outperforming static Path ORAM ($15.0\,\text{ms}$) by $10.2\times$.
