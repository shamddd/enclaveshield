\section{Limitations}
\label{sec:limitations}

We acknowledge the following limitations:
\begin{enumerate}
    \item \textbf{Hardware Enclave Emulation}: Experiments were conducted using software TEE emulators; deployment on physical Intel TDX and AMD SEV-SNP hardware platforms represents ongoing work.
    \item \textbf{ZK Proof Generation Overhead}: Generating zk-SNARK attestation proofs incurs initial setup costs prior to enclave session establishment.
\end{enumerate}
