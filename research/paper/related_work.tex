\section{Related Work}
\label{sec:related_work}

\paragraph{Controlled-Channel Attacks on TEEs}
Xu et al. \cite{xu2015controlled} demonstrated controlled-channel page-fault attacks on Intel SGX. Foreshadow \cite{vanbulck2018foreshadow} extracted enclave secrets via L1 Terminal Fault speculative execution.

\paragraph{Oblivious RAM & Side-Channel Defenses}
Path ORAM \cite{stefanov2013pathoram} established tree-based memory access obfuscation. Ohrimenko et al. \cite{ohrimenko2016oblivious} explored oblivious machine learning in enclaves. EnclaveShield extends this literature by introducing adaptive frequency-based ORAM page balancing and Zero-Knowledge attestation.
